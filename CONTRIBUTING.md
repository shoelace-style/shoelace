# Contributing to Shoelace

**Shoelace is sunset**—this repository is not accepting issues, pull requests, or feature requests.

**Web Awesome** is the active successor (same lineage and goals as Shoelace). Please contribute there:

- [webawesome.com](https://webawesome.com)
- [github.com/shoelace-style/webawesome](https://github.com/shoelace-style/webawesome)

Historical Shoelace contribution guidelines (for reference only): [shoelace.style/resources/contributing](https://shoelace.style/resources/contributing)
